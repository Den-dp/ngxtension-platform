## Quick Start 🚀

<div class="quick-start-grid">
	<div class="install-block">
		<div>
			### Get Started
			Install **ngxtension** using your favorite package manager and start building modern Angular apps today.
		</div>

    	<div class="code-window">
    		<div class="window-header">
    			<div class="window-dot dot-red"></div>
    			<div class="window-dot dot-yellow"></div>
    			<div class="window-dot dot-green"></div>
    		</div>
    		```bash
    		npm install ngxtension
    		```
    	</div>

    	<div>
    		### Why ngxtension?
    		"It provides the utilities that I wish were built into Angular. It makes my code cleaner and my signals more powerful."
    	</div>
    </div>

    <div class="code-window">
    	<div class="window-header">
    		<div class="window-dot dot-red"></div>
    		<div class="window-dot dot-yellow"></div>
    		<div class="window-dot dot-green"></div>
    	</div>

    	```angular-ts
    	import { linkedQueryParam } from 'ngxtension/linked-query-param';

    	@Component({
    		template: `
    			<input [(ngModel)]="search" />
    		`,
    	})
    	export class MyComponent {
    		readonly search = linkedQueryParam('q');
    	}
    	```
    </div>
